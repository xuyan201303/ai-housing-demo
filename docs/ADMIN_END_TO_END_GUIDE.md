# 社員向け：資料の登録・確認・公開（隔離受入確認用）

この環境は**隔離受入確認データ**です。Customer の回答は **TEST provider** によるもので、通常の営業資料・本物の AI 回答・音声受入確認ではありません。確認チェックと公開は、内容を照合した人が明示的に行います。

## はじめて資料を公開するとき

1. **取り込む**：「資料管理」→「PDF / Excel を選択」で資料を登録し、「SDK解析を実行」。解析しただけでは公開されません。
2. **照合する**：「SDKが読み取った本文（原文・変更不可）」と出典を確認し、「物件情報」「設備情報」「FAQ」「住宅ローン」の必要項目を普通のフォームで整理します。手入力しても SDK 原文は変わりません。FAQ の質問・回答、設備、金利の「適用条件」は追加・修正・削除できます。
3. **保存・確認する**：「知識範囲」、出典・期限、「資料用途」を照合し、確認メモを記入して「下書きを保存」。未完成でも保存・再開できます。内容が揃ったら、照合チェックを付けて「管理者確認を保存」。不足がある場合は、表示された項目を修正して再保存します。対客用は「顧客への案内に使用可」、社内資料は「社内専用」です。
4. **公開する**：「公開管理」→「公開内容を編集」→「初めての公開草案を作成」。確認済み資料を「資料を追加」で選びます。「変更の説明」を入力して「公開草案を保存」→「公開前の差分を確認」。追加・維持・除外、注意事項を照合して公開チェックを付け、「この内容で新しい版を公開」。

**下書き保存 ≠ 内容確認 ≠ 公開**です。確認成功と公開版作成の表示は別です。未保存の変更がある場合は、資料・画面を切り替える前に保存してください。

## 今回、ユーザーにお願いする短い確認

1. 「資料管理」で **住宅購入基礎FAQ_demo.pdf** を開き、更新理由を入力して「登録内容を修正する」。
2. 「FAQ」で一つの回答を、元資料に沿って短く整理し「下書きを保存」。再読み込み後に同じ資料を開き、内容が残っていることを確認します。
3. 内容・出典・用途を照合し、確認メモを保存して、照合チェック→「管理者確認を保存」。ここでは旧公開版の接客は変わりません。
4. 「公開管理」で現在版から草案を作り、その資料だけ新しい確認改訂へ差し替えます。他の資料を除外せず、保存→差分を確認。正しければ、公開チェック→明示公開します。
5. Customer で「**文字で開始**」を押して新しい接客を開始し、FAQ の質問を入力。画面の公開版と新しい回答を確認します。開始済みの有効な接客は元の版を保ちます。終了は「接客終了」です。今回はマイクを使いません。

日常操作で JSON は不要です。未知の拡張項目は「開発・診断用の詳細」に保持しています。通常環境への切り替え、実 AI・音声確認は別途承認が必要です。
