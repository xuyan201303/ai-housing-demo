# Demo操作手順（会社AI接客員）

Customer は住宅購入・購入手続・住宅ローンの相談から始めます。No.15は明示対象の物件サンプルで、初期表示・初回挨拶・一般相談・未選択のローン計算には自動適用しません。

[接客定位、6資料確認表、正常Admin公開と人工マイク受入れ](CONSULTATION_POSITIONING.md) を現在の手順としてください。従来の操作書は `evidence/consultation_positioning/DEMO_WALKTHROUGH_before.md` に保存しています。

正常入口は http://localhost:5173/、管理は /admin、Staff は /staff、Backend は127.0.0.1:8000です。隔離5174/8001は別DBです。TESTデータを正常DBへコピーしません。

現在、正常資料はSDK解析済み6件・確認0件・公開版なし。一般相談Sessionはこの状態でも開始できますが、未確認資料の事実は回答に使いません。Adminで6件を確認・全件選択して公開後、新しい接客を開始してください。

## 短い接客例

1. 「接客を開始」してマイクを許可。一般相談を歓迎する挨拶。
2. 「住宅購入は何から始めればよいですか？」→ 共通資料・出典。「駅から何分ですか？」→ 対象確認。
3. 「No.15の価格と設備を教えてください」→ 明示物件・資料連動。「資料を閉じる」→ 会話中心。
4. 終了して新規接客。「借入額は3000万円です」「35年で考えています」「三菱UFJ銀行の変動金利でお願いします」→ 物件未選択のBackend概算。現在資料で87,439円/月（1.195%）。Flat35は取得価格も確認します。
5. 「この年収なら、ローン審査に絶対通りますか？」→ 断定しない・Staff呼出。Staffで同じSessionの「受付」「対応完了」を確認。
6. 「接客終了」→ マイク・再生・Realtime終了。

文字は「文字で開始」から同じ内容を入力できます。金額はBackend結果を使い、モデルに計算させません。音声と字幕・カードの額と条件を照合してください。

## 公開と版更新

公開は、選択した全資料による新しい版です。前版の資料を自動継承しません。共通・会社資料は物件価格の期限を延長しません。接客中の版は固定され、新規接客だけ新版を使います。更新資料は再取込・SDK解析・業務確認・公開で適用します。SDK rawは確認編集で変更しません。

会社資料は未登録。会社固有の営業時間・サービス・保証・購入手順を補いません。No.15の期限は2026-10-15、金利は10月中、共通FAQのDemo再確認期限は11月6日。公式制度の失効日とは区別します。

物理マイク・実スピーカー・ユーザー受入れは未確認です。合成入力の実Realtime検証と分けて記録します。
