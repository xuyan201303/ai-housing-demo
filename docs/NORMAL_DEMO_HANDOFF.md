# 正常Demo：最短の人工操作

1. http://localhost:5173/admin にログイン。既にSDK解析された6件を順に選び、raw・出典・日付・範囲を照合。FAQ2件は「共通住宅購入知識」、物件3件は「具体物件」、参考金利XLSXも「共通住宅購入知識」（商品条件Toolで利用）。
2. 各資料の確認メモ・確認チェック → 「管理者確認を保存」。6件を公開対象にチェック → 「選択資料を公開」。重複アップロードは不要。
3. Customerを刷新し、新しい接客を開始。初期表示に物件詳細は出ず、一般相談の歓迎から始まります。
4. 実際のMacマイクで、一般購房質問 → 対象未確定の駅質問 → 明示No.15の価格・設備 → 資料を閉じる、を確認。
5. 新規接客で「借入額は3000万円です」「35年で考えています」「三菱UFJ銀行の変動金利でお願いします」。未選択物件の計算、金額・条件・字幕・カードを照合。
6. 審査の断定質問 → 正常Staffで同じSessionの受付・対応完了 → Customer同期 → 「接客終了」。

詳細な発話例・資料確認表は [CONSULTATION_POSITIONING](CONSULTATION_POSITIONING.md)。声の聞きやすさ、字幕、金額、遅延、AI自身の音声の再認識、終了後の採取停止を観察してください。
