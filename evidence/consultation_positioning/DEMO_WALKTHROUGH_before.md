# Demo操作手順

対象は「コモンステージ八千代中央 分譲住宅 No.15」、基準日2026-10-07。物件は期限2026-10-15、金利は2026-10-31です。期限だけ延ばさず、公式情報を再確認した資料を新しく取り込んでください。

OpenAI API Key設定を反映し、実文字回答とChrome／日本語テスト音源を使った実Realtime音声を確認しています。物理マイク・スピーカーの現場確認は別に必要です。通常Demoの資料は、管理者が確認・公開してから接客を開始します。

**現在の正常Demoは4資料のアップロード・SDK解析まで準備済みです。再アップロードは不要です。** [正常準備記録・4資料確認表](../evidence/normal_demo_preparation.md) を照合し、下記の管理者確認・公開から進めてください。Chromeでの短い人工操作と連続音声の手順は [NORMAL_DEMO_HANDOFF](NORMAL_DEMO_HANDOFF.md) にまとめています。実接客の受入れは正常5173で行い、隔離5174の結果で代替しません。

## 事前準備

1. [README](../README.md) の2つのコマンドでBackend・Frontendを起動します。
2. ローカル `.env` のAdmin / Staffパスワードを使います。Keyを変更したらBackendを再起動します。
3. Chromeに接客 `/`、管理 `/admin`、Staff `/staff` の3タブを開きます。
4. [公式出典](../research/SOURCE_MANIFEST.md) と [資料説明](DEMO_DOCUMENTS.md) のNo.15・日付・金利条件を照合します。
5. 音声実演にはマイク・スピーカー・外部API通信が必要です。ページを開いただけでは発声しません。

このMacには隔離確認用 [接客ページ](http://127.0.0.1:5174/) も起動しています。公開資料名に「Chrome検証」とあるTEST DBを使い、通常の :5173 と別の履歴になります。現場マイク確認はこのページで「接客を開始」→「駅から何分ですか」→音声・字幕確認→「接客終了」で行えます。

## 資料取込・確認・公開

管理ページへ `admin` とローカルパスワードでログインします。4資料を1件ずつ取り込みます。

- `demo_documents/物件概要_demo.pdf`
- `demo_documents/設備仕様_demo.pdf`
- `demo_documents/周辺環境_demo.pdf`
- `demo_documents/住宅ローン_demo.xlsx`

各資料：

1. 「PDF / Excelを選択」でアップロード。`uploaded` になります。
2. 資料を選び「SDK解析を実行」。実SDK成功時だけ `parsed`、失敗は実エラーです。
3. 「SDK raw結果」「標準化結果」で値、ページ／シート・行、資料名を確認します。
4. 「業務確認・編集」で号地・値・日付・条件を照合します。JSON編集は元SDK rawを書き換えません。
5. 確認メモ・確認チェックを入れ「管理者確認を保存」。`confirmed` になります。
6. 全4件が確認済みになったら、全件を公開対象に選び「選択資料を公開」。`published` と新しい版が作成されます。

物件名・号地・価格を持つ概要が必要です。設備や金利だけで完全な物件版は作れません。公開は選択全資料による版の置換で、前版の資料が自動で残る方式ではありません。

照合の要点：

- No.15：76,900,000円、土地139.85㎡、建物93.25㎡。
- 3LDKは公式No.15図面からの分類で、本文の明記ではありません。
- 駅の最長徒歩12分・920〜950mは4戸の掲載範囲。`walking_minutes` にNo.15単独値を登録していません。
- 駐車2台可能とは断定しません。公式蓄電「4.9kW」をkWhへ訂正しません。
- 金利は年利％の数値。1.195は1.195％。月次期間の開始日と公表日を混同しません。
- フラット35の3.83％は融資率9割以下、9割超は参考3.94％です。

FAQ・金利更新は解析済み新資料の「確認データJSON」で行います。FAQは `faq` 内の `question` / `answer`、金利は `rates` 内の期間・利率・年数・融資額条件・出典です。確認済み資料を直接変更せず、新資料で確認し直します。referenceはBackendが対象資料に結び付けます。

## 5分の接客実演

資料の管理者確認・公開とOpenAI実接続を事前確認した状態で行います。Key未設定ならAI工程はBLOCKEDと説明し、次項の非AI操作を実演します。

| 目安 | 操作 | 確認結果 |
| --- | --- | --- |
| 0:00 | 「接客を開始」、マイクを許可 | WebRTC接続後にAI日本語挨拶、接客版を表示 |
| 0:30 | 「この物件のおすすめポイントは？」 | 公開資料の説明、参照名・字幕 |
| 1:00 | 「駅から何分ですか？」 | 4戸の最長12分という限定を維持。No.15単独12分と断定しない |
| 1:30 | 「どんな設備がありますか？」 | SDK取込・確認・公開済み設備、参照 |
| 2:00 | 「住宅ローンだったら月いくらですか？」 | 頭金・年数・商品を確認後、Backend Tool計算 |
| 3:00 | 「年収500万円なら絶対ローン通りますか？」 | 審査を断言せず、方針説明と実Staff呼出 |
| 3:30 | Staffで呼出を確認し「受付」 | Customerに「スタッフが確認しました。」 |
| 4:15 | Staffで「対応完了」 | Customerに完了状態 |
| 4:45 | 「接客終了」 | Session・マイク・音声接続を終了 |

文字なら「文字で開始」から同じ質問を入力します。テスト音源で確認したWebRTC・実AI音声・字幕と、物理マイクでの現場受入れは分けて報告します。

## Key未設定でも確認できる動作

公開資料で「文字で開始」するとSessionを作成できます。通常質問は `OPENAI_NOT_CONFIGURED` エラーになります。

ローンフォームで頭金 `5000000` 円、35年、フラット35を選び「月額概算を計算」。公開価格76,900,000円から借入71,900,000円・融資率約93.50％となり、参考3.94％を使います。概算月額315,773円、計算日・条件・注意文を確認します。実Backend計算とAI回答検証は別です。

「スタッフを呼ぶ」で相談内容を送信します。Staffへ `staff` とローカルパスワードでログインし、同じSession・物件・直前質問の通知を確認します。「受付」「対応完了」を順に押し、Customerで実状態の同期を確認します。間隔は約2秒です。

審査断定質問はBackend方針で引継ぎます。「システム案内」はモデル生成回答と区別して表示します。

## バージョン更新

1. 更新前Sessionを開始し、公開版番号を控えます。
2. 正式情報を再確認した更新資料をアップロード・SDK解析・管理者確認。
3. 公開対象から対応する旧資料を外し、必要な設備・周辺・金利を含む完全な選択で新版公開。
4. 別タブで新Sessionを開始し、新版と値を確認。
5. 更新前Sessionは元の版を保持することを確認。旧・新情報を混合しません。

テストの架空価格変更は独立test DB専用。実Demoへ架空新価格を投入しません。

## 資料外・エラー・履歴

資料にない事実を質問し、「確認できる資料に記載がない」とStaffへ案内することを確認します。Key未設定中はこの生成回答の受入れもBLOCKEDです。

解析・OpenAI・金利期限・商品条件エラーは実エラーです。資料を勝手に公開せず、別パーサー・mockへ切り替えません。期限切れSessionでもStaff呼出は使えます。

Admin「接客履歴」で発話・回答・時刻・Tool・Staff呼出・出典・版を照合します。「公開バージョン」で公開選択を確認します。

最新実測は [acceptance](../evidence/acceptance.md)、[SDK Smoke](../evidence/sdk/smoke_result.json)、[HTTP acceptance](../evidence/http_acceptance.json)。コード、テスト、実AI接続、実音声、利用者受入れを同じ完了状態にまとめません。
